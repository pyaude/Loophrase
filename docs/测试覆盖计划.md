> 基于 29 个源文件，按优先级分 4 层规划测试用例。

## 测试技术栈

| 组件 | 选型 |
| --- | --- |
| 测试框架 | Jest (jest-expo preset) |
| TypeScript | ts-jest |
| 组件测试 | @testing-library/react-native |
| Mock 策略 | moduleNameMapper 映射 expo-* / supabase 到 `src/__mocks__/` |

## 覆盖率目标

| 层级 | 目标覆盖率 | 说明 |
| --- | --- | --- |
| P0 — 纯逻辑/核心业务 | ≥ 90% | 无 RN 依赖，最高 ROI |
| P1 — 服务层（含外部依赖 mock） | ≥ 80% | mock expo-* 模块 |
| P2 — Repository 层 | ≥ 75% | mock SQLiteDatabase |
| P3 — UI 组件 | ≥ 60% | @testing-library/react-native |
